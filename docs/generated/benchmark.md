# Benchmark: this implementation vs the Java ShinyProxy 3.2.4

Generated by `scripts/benchmark.sh` on 2026-08-15T16:31:47Z (commit `80ef669`).

Both servers ran the same configuration with the Docker backend, one after the other, on the same machine.
Every load phase ran for 25 seconds with 32 connections; the WebSocket phase held 100 connections open. The app start/stop numbers are the median of 5 cycles.

The `index` and `api` phases give every connection its own user session, because a servlet container serialises the requests of one session; the proxy phases necessarily share the session of the user that owns the app.
